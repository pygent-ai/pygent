# Context 第一原则

本文从属于 [Pygent 0.2 第一原则](../FEATURES.md)。只能澄清，不能与其冲突。

1. **当前有效快照**：Context 作为 Module 的第二个输入和输出显式传递，只表示本次数据流当前生效的提示词、历史、工具描述和请求事实，不是历史版本仓库。
2. **不可变值**：任何历史演进都产生新 Context，旧值永不改变。
3. **数据而非服务**：Context 不持有连接、锁、Store、handler 或运行资源。
4. **写入可见**：当前 Message 不会自动进入历史，调用者明确决定追加时机。
5. **持久化外置**：加载、提交、历史版本、revision、审计和冲突处理属于框架外部的业务服务。
6. **显式槽位更新**：无槽位 Message 正常追加；带稳定 `slot` 的 Message 替换旧的同槽位值，使 Context 保留该槽位当前有效内容。
7. **可见性不是授权**：`Context.tools` 描述本次上下文和模型可见的工具，不构成可信授权证明；实际授权由用户开发的自定义授权 Module 或受信执行适配器决定。
